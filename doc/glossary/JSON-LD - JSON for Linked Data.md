# JSON-LD - JSON for Linked Data

**JSON-LD** (JSON for Linked Data) is a method of encoding Linked Data using JSON. It is designed to make it easier to create machine-readable data that can be interlinked and understood across different systems on the web. JSON-LD extends standard JSON by adding a context that maps terms to IRIs (Internationalized Resource Identifiers), allowing data to be semantically enriched without sacrificing the simplicity and familiarity of JSON syntax.

## Purpose and Applications

JSON-LD is particularly useful for search engine optimization, as it allows websites to provide structured data that search engines can easily parse and understand. It is widely used for schema.org markup, enabling rich snippets in search results. JSON-LD provides a way to express Linked Data principles while maintaining compatibility with existing JSON-based systems, making it accessible to developers who may not be familiar with RDF or other semantic web technologies.
